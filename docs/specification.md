# HUNOR App V1 – specifikáció

## Cél
Belső iOS alkalmazás a HUNOR állomány nyilvántartására, elérhetőségére, saját maguk által megadott képességeire és közös eseménynaptárára.

## V1 funkciók
- bejelentkezés (backend integráció következő fázis)
- saját profil
- rendfokozat, munkahely, beosztás
- saját képességek szabad szöveges kezelése
- elérhetőségi státusz
- szabadság időszak kezelése (backend integráció következő fázis)
- taglista és név/képesség keresés
- közös naptár
- esemény részletei és részvételi jelzés

## Státuszok
- Elérhető
- Szabadságon
- Beteg
- Képzésen
- Egyéb

## Következő fejlesztési fázis
- Supabase autentikáció
- központi PostgreSQL adatbázis
- jogosultságok
- valós idejű szinkronizáció
- push értesítések
- admin felület
- naptár CRUD
